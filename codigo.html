Entorno

python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt

Versiones de referencia (las usadas para producir las cifras publicadas): Python 3.13.16, NumPy 2.5.3, pandas 3.0.5, SciPy 1.18.1, scikit-learn 1.9.1, statsmodels 0.15.0, factor_analyzer 0.5.1, libpysal 4.15.0, esda 2.10.0, spreg 1.9.1, GeoPandas 1.2.0, Shapely 2.1.2, Matplotlib 3.11.2. Con otras versiones, los resultados con simulación pueden diferir en cifras decimales.

Scripts del informe
ScriptProducto
00_datos.pyReconstruye el dataset de 82 cantones desde los paneles, lo coteja con el publicado, agrega población 2023, área, densidad y región; auditoría A01–A03 y sumas SHA-256 de las entradas.
01_descriptivo_correlacion.pyDescriptivos, extremos de Tukey, 21 correlaciones (Pearson/Spearman, IC de Fisher y bootstrap, FDR).
02_pca.pyKMO, Bartlett, análisis paralelo, varimax, puntajes rotados, cuadrantes, transición, bootstrap, sensibilidad S1–S7, exclusión de un cantón.

04_ejercicio2.pyQ3 frente al resto (Mann-Whitney, rank-biserial, TOST), ajuste por densidad y región, exclusión de un dominio, paneles A/B del eje de seguridad.

06_rezago.pyÍndice de rezago relativo y 13 escenarios de sensibilidad.
07_figuras.pyLas diez figuras (paleta Okabe-Ito) y su texto alternativo.
09_validacion_independiente.pyReimplementación con NumPy/SciPy de los cálculos centrales y comparación con las librerías.

Los resultados de cada verificación quedan registrados en informe/resultados_referencia/verificacion_reproduccion.json y articulo/verificacion_reproduccion.json. Tiempos aproximados: informe, 5 minutos; artículo, 25–30 minutos.

Alcance de esta verificación. Demuestra que el código reproduce las cifras publicadas con las versiones fijadas; no demuestra que la metodología sea la adecuada. Las versiones de jenkspy (0.4.1) y scikit-posthocs (0.17.0) son las de esta reejecución; la sesión original no las registró.

Buenas prácticas incorporadas

  • Semillas fijas y declaradas; versiones exactas en requirements.txt.
  • Dos controles distintos: reproducción de cifras y validación metodológica independiente.
  • Sumas SHA-256 de todos los archivos de datos publicados.
  • Rutas relativas: los scripts no dependen de carpetas de una sesión particular; la carpeta de insumos puede cambiarse con la variable de entorno ENTRADAS.
